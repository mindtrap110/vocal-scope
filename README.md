# 보컬 스코프 3.4.0

기존 보컬 스코프의 사용 흐름(자유 측정, 목표음, ±15 cent, 안정도, 최근 12초 그래프)을 유지하면서 음정 검출과 UI를 다시 설계한 설치형 PWA입니다.

## 주요 변경
- 판단 보정 전용 흐름: M1 8음 → A 12회 × 2블록, 직접 편집 가능한 오늘 목표음 순서
- ② 및 재시도에서 실제 음정·그래프·과거 결과 숨김, 방향·크기·확신도를 저장한 뒤에만 결과 공개
- 첫 유효 음정 검출 기준 0.5~2.5초의 부호 있는 목표 오차 중앙값을 주 결과로 표시. 짧거나 끊긴 구간은 유효 점수로 대체하지 않음
- 각 측정의 시작에서 음정 평활·옥타브 연속성 필터를 초기화해 이전 회차가 새 목표음에 영향을 주지 않게 함
- 맥놀이 블록은 화면 없이 2초 교정 + 울렁임 Y/N, 화면 블록은 실시간 안내로 2초 교정. 두 블록 모두 기준음을 끈 3초 재시도로 평가
- 날짜·블록·회차·②/교정/재시도·판단·울렁임·피드백 단계·전후 목 상태를 저장하고 JSON/TXT 공유에 포함
- 합성 기준음의 1회/지속 재생 및 켜기/끄기. ②와 재시도 전에 자동으로 끄고, 앱 전환 시 중단
- 중단·재접속 시 판단 전 가림 상태 복구, 판단 미입력 기록의 공유 차단, 피드백을 줄이는 회차의 결과 비공개
- 하루 결과에서 M1 판단 정확도·‘맞음’ 정밀도·확신도별 정확도 및 블록별 재시도 결과 비교. 연습 기록 보관 한도를 2,000개로 확대
- YIN 기반 기본주파수 검출 + 2:1 다운샘플링으로 G2 같은 저음에서도 충분한 주기 확보
- 주변 소음 바닥을 실시간으로 추정하는 자동 입력 게이트
- 단발성 1옥타브 오인식을 3프레임 지속 여부로 구분하는 연속성 보정
- 최근값 smoothing과 note stability를 분리해 반응성과 안정성을 함께 확보
- 무거운 음정 계산을 Web Worker로 분리해 그래프/UI 끊김 감소
- 입력 dB, 소음 바닥, 판정 문턱, 검출 신뢰도를 화면에서 직접 확인 가능
- 최근 12초 그래프에서 한 가로줄 = 정확히 반음, 목표음 점선 표시, 그래프 고정 기능
- 짧은 가사 구절을 기기에 저장하고 화면에 크게 띄운 채 테이크별로 반복하는 가사 구절 연습
- 구절별 선택 첫 음 재생, 실제 음정 흐름·음역·유효 음성 시간 기록, 과거 구절 즉시 재연습
- 저장된 기록을 보컬 코칭 요청문과 함께 iPhone 공유 시트로 보내거나 클립보드에 복사
- ChatGPT에 공유할 최근 기록 수를 직접 입력해 필요한 세션만 선택
- 선택한 기록의 전체 음정 좌표를 ChatGPT가 받기 쉬운 상세 TXT 파일로 공유하고, 같은 범위만 JSON으로 내보내기
- iOS 공유 시 별도 안내문 때문에 실제 데이터 파일이 누락되던 문제 수정
- 전체 기록·음정 좌표·가사 구절을 버전이 명시된 JSON 파일로 내보내기 (음성 녹음은 포함하지 않음)
- 선택적으로 측정과 동시에 음성을 녹음하고 IndexedDB 기기 저장소에 연습 기록과 연결해 보관
- 기록 상세 및 녹음 목록에서 재생·공유·파일 저장·개별 삭제, 전체 녹음 용량 확인
- iPhone에서는 지원 포맷을 감지해 AAC/MP4 계열을 우선 사용하고 다른 브라우저에서는 WebM/Ogg로 대체
- iOS에서 마이크/AudioContext가 꼬인 경우 오류 메시지와 재로드 복구 버튼 제공

## 설치 조건
PWA와 마이크는 HTTPS 환경이 필요합니다. 정적 호스팅(GitHub Pages, Cloudflare Pages, Netlify, Vercel 등)에 이 폴더 내용을 그대로 올린 뒤 Safari에서 주소를 열고 홈 화면에 추가합니다.

## 첫 측정
1. 처음에는 AirPods를 분리하고 조용한 곳에서 테스트합니다.
2. iPhone을 얼굴에서 약 30~50cm 떨어뜨립니다.
3. `마이크로 측정 시작`을 누르고 마이크 권한을 허용합니다.
4. 편한 크기로 `아—` 또는 `우—`를 2~3초 유지합니다.
5. 화면 아래 `입력 상태`에서 소리 감지와 검출 신뢰도를 함께 확인합니다.

## 테스트
`node tests/judgement-test.cjs`

중앙값 구간, 짧고 끊긴 음정, ±25 cent 경계, 목표음 순서, 피드백 일정, 교정 전/재시도 비교, 저음 검출 회귀를 검사합니다.

`NODE_PATH=/path/to/test/node_modules node tests/judgement-flow-test.cjs` (jsdom 26 필요)

실제 HTML과 전체 앱 스크립트를 로드해 판단 전 가림, 기록/공유 보호, 재접속 복원, M1→블록→교정→재시도, Y/N, 중단, 피드백 줄이기, 일일 보고를 검증합니다. 이 검증은 마이크·오디오를 모사하며 실제 iPhone 청취/녹음을 대신하지 않습니다.

`BROWSER_EXECUTABLE=/path/to/chromium BROWSER_FAKE_AUDIO=/path/to/voice-80c.wav node tests/judgement-browser-test.cjs` (Playwright 필요)

목표 A2보다 80 cent 높은 48kHz 모노 WAV를 마이크 입력으로 사용해 Chromium의 실제 분석/MediaRecorder/IndexedDB를 검증합니다. 기대 결과는 +80 cent 중앙값, 판단 전 비공개, 라벨이 연결된 녹음 저장/재생입니다. 실제 iPhone 기기 검증은 별도로 필요합니다.

## 판단 보정 사용법
1. 일반 화면에서 필요하면 연습 녹음을 켭니다.
2. 판단 보정 카드에서 날짜·블록 순서·목표음 순서를 확인하고 시작합니다. 기본은 홀수 날짜에 맥놀이→화면, 짝수 날짜에 화면→맥놀이이며 직접 바꿀 수 있습니다.
3. 기준음을 들은 뒤 2초 쉬고 중간 음량으로 3초 유지합니다. 세 항목의 판단을 저장한 뒤 결과를 봅니다. ±25 cent 이내는 ‘맞음’입니다.
4. A에서 오차가 25 cent를 넘고 결과를 확인하는 회차라면 해당 블록의 2초 교정과 화면을 가린 재시도를 진행합니다. 맥놀이 Y/N은 교정이 시작될 때의 울렁임에만 붙입니다.
5. 훈련 끝 또는 잠시 중단 후 기록 공유에서 원하는 개수를 JSON/TXT로 내보냅니다. 판단 미입력 기록은 내보내지 않습니다.

### 결과의 범위
- 0초는 버튼을 누른 때가 아니라 첫 유효 음정 검출입니다. 중앙값은 500~2500ms 표본에만 적용합니다.
- 2초 교정은 평가 구간 전체를 채우지 못하고 기준음과 목소리도 섞이므로 `correction-only`로 표시합니다. 화면 교정의 실시간 수치는 조정 안내이며 최종 오차가 아닙니다.
- 피드백을 줄이는 회차도 측정과 판단은 저장합니다. 그 회차는 교정 없이 다음으로 이동하고, 실제 오차는 앱 화면에 공개하지 않습니다. 수치는 나중에 분석용 내보내기에 포함됩니다.
- 원본 음정 좌표·기존 착지/유지/드리프트/±15 cent 지표는 참고 항목으로 보존하고, 새 0.5~2.5초 지표 및 ±25 cent 판단과 구별합니다.
- 사이트 데이터 삭제 시 기록과 녹음도 삭제될 수 있으므로 중요한 결과는 파일로 보관합니다.
