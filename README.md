# 보컬 스코프 3.9.3 — A′ 연습 날짜 선택

일반 녹음은 기존 녹음 버튼으로 사용하며, 판단 보정 훈련은 선택적으로 켭니다.

## A′: 방금 부른 녹음을 듣고 판단 비교

1. ‘판단 보정 훈련’을 켜고 **훈련 모드 → A′ · 녹음 듣고 비교**를 선택합니다. 그 아래 **연습 날짜**에서 진행할 날짜를 고르고, 새 날짜라면 목표음 12개를 확인합니다. 기준음·녹음·재생이 진행 중일 때는 끝난 뒤 날짜를 바꿀 수 있습니다. 진행이 저장된 날짜를 고르면 그날의 목표음과 진행 상태를 불러옵니다.
2. 기존 기준음을 2초 듣고 3초 부릅니다. 기존 모드와 같은 마이크 분석을 시작하고, 이미 분석에 들어오는 입력 파형에서 첫 음정 검출 기준 3초를 메모리에 복사합니다. 별도 녹음 모듈의 준비를 기다리지 않습니다.
3. 실시간 판단의 방향·크기·확신도를 선택하고 **재생**을 누릅니다. 방향이 ‘맞음’이면 크기는 비워 둡니다.
4. 같은 기준음 1초 → 0.5초 쉼 → 녹음 3초를 한 오디오 파일로 이어 재생합니다. 녹음은 별도 증폭·정규화 없이 재생합니다. 첫 재생을 마치면 판단을 저장하거나 한 번 더 들을 수 있습니다.
5. 재생 판단의 방향·크기·확신도를 선택하고 **재생 판단 저장 · 결과 공개**를 누릅니다. 두 판단이 잠기고 오차가 표시됩니다. 공개 뒤 **다시 듣기**는 제한 없이 사용할 수 있습니다.
6. **다음 시행**으로 진행합니다. 기존 교정 조건에 해당하면 별도의 **화면 교정** 버튼이 보이며, 사용한 경우 그 시행에 기록됩니다.

내보낼 날짜를 고르고 **A′ CSV 내보내기**를 누르면 두 판단을 마친 시행을 한 줄씩 저장합니다. 날짜, 실제 녹음 시각(ISO UTC), 시행 번호, 목표음, 오차, dBFS, 두 판단의 방향·크기·확신도, 공개 전후 재생 횟수, 화면 교정 사용 여부, 마이크 설정이 포함됩니다. ‘맞음’이나 이전 버전에서 저장한 판단의 크기 열은 비워 둡니다. 판단을 마치지 못한 A′ 시행은 앱에서 결과와 내보내기를 잠급니다.

**A′ WAV 묶음 내보내기**는 현재 페이지 메모리에 있는 완료 녹음을 16비트 모노 WAV로 변환해 ZIP으로 저장합니다. 파일명 예: `2026-11-10_01_A2.wav`. 페이지를 닫거나 새로고침하기 전에 내보내세요. WAV와 달리 이미 저장한 판단 기록은 페이지를 다시 열어도 남습니다. 첫 듣기가 중단되면 남은 재생 횟수로 다시 들을 수 있습니다. 두 번 모두 중단되거나 페이지를 다시 열어 녹음이 사라지면 미완료 시행을 다시 녹음합니다.

마이크는 기존 코드와 동일하게 에코 제거·잡음 제거·자동 증폭을 끄도록 요청합니다. A′는 `getSettings()`에서 브라우저가 보고한 값만 표시·기록합니다. 값이 없으면 ‘확인 불가’이며, 기기 전체의 음성 처리까지 비활성화됐다는 뜻은 아닙니다.

A′에서 발성을 인식하지 못하면 소리 크기 막대를 확인하세요. 입력 신호가 없는 경우, 신호가 들어왔지만 음정을 잡지 못한 경우, 음정은 잡혔지만 재생용 파형이 끊긴 경우를 각각 안내합니다.

## 기존 판단 훈련(v3a)

## 하루 훈련

- 입력한 날짜로 화면(screen) 1블록 × 12회를 진행합니다. 날짜 홀짝 배정과 beat 블록은 없습니다.
- 목표음 12개를 순서대로 붙여 넣습니다. 예: E3 D#3 F3 D#3 G3 D3 B2 C3 C#3 C3 A2 A#2
- 기준음 2초 → 화면을 가리고 3초 부르기 → 방향·크기·확신도 판단 → 결과 공개 순서입니다.
- 실제 오차가 ±25¢ 이내인지에 따른 판단 채점은 기존과 같습니다.
- 교정은 |오차|가 교정 기준(기본 100¢)을 초과한 회차 중 앞에서부터 최대 횟수(기본 3회)까지만 합니다. 100¢ 이하와 한도 소진 뒤에는 다음 회차로 넘어갑니다.
- 화면에 교정 n/3을 표시합니다. 최대 횟수를 바꾸면 분모도 바뀝니다. 기준·최대 횟수는 시작 전 또는 회차 사이에 설정하고 기기에 저장합니다.
- 화면 교정은 기준음을 켜고 실시간 음정을 보며 2초 맞춘 뒤 직접 정지합니다. 이후 기준음을 끄고 화면을 가린 3초 재시도를 합니다. 재시도에는 판단 입력이 없습니다.
- 실패한 initial/retry는 discarded로 남기고 해당 단계만 다시 진행하는 기존 동작을 유지합니다.
- 피드백 단계 0/1/2는 기존처럼 직접 선택합니다. 결과를 공개하지 않는 회차는 판단만 저장하고 교정 없이 다음 회차로 갑니다.

## 저장과 복원

- 새 훈련 레코드 training에 protocol: "v3a", block: 1, method: "screen", trial: 1~12를 저장합니다.
- 교정한 회차의 initial·correction·retry에는 같은 correctionIndex(기본 한도에서 1~3)를 저장합니다. 나머지는 null입니다. 최대 횟수를 늘리면 그 한도까지 순번을 사용합니다.
- correction/retry는 initialSessionId로 해당 initial과 연결합니다. screen 교정의 mixedWithReference: true를 유지합니다.
- 교정 횟수는 해당 날짜의 v3a 기록을 기준으로 복원하므로 앱을 다시 열어도 초기화되지 않습니다.
- 이전 버전의 저장 기록과 진행 데이터는 보존합니다. v3a 진행은 별도 키에 저장하며 이전 24회 진행을 새 12회로 바꾸지 않습니다.
- 일반 녹음의 training은 null입니다. 음성 파일 저장 설정과 기기 오디오 입력 설정은 기존과 같습니다.

## 음량과 평가

- assessment의 첫 음정 검출 후 500~2500ms 오차 중앙값 계산은 변경하지 않았습니다.
- levelDb의 같은 구간 입력 RMS(dBFS, 소수 한 자리) 계산도 변경하지 않았습니다. 짧은 교정은 실제 수집한 구간만 사용합니다.
- initial/retry 녹음 중에는 음정을 가리고 크기 막대만 표시합니다. 목표 크기는 기본 빈칸, 허용 폭은 기본 ±4dB입니다. 목표 범위 안은 초록, 밖은 회색입니다.

## 내보내기

하루 파일 vocal-scope-training-YYYY-MM-DD.json에 날짜가 같은 모든 stage를 createdAt 순으로 넣습니다. 이전 기록도 판단 유무로 제외하지 않습니다. levelDb와 하루 initialLevelDbMedian을 유지합니다.
