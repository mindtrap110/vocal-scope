# 보컬 스코프 2

기존 보컬 스코프의 사용 흐름(자유 측정, 목표음, ±15 cent, 안정도, 최근 12초 그래프)을 유지하면서 음정 검출과 UI를 다시 설계한 설치형 PWA입니다.

## 주요 변경
- YIN 기반 기본주파수 검출 + 2:1 다운샘플링으로 G2 같은 저음에서도 충분한 주기 확보
- 주변 소음 바닥을 실시간으로 추정하는 자동 입력 게이트
- 단발성 1옥타브 오인식을 3프레임 지속 여부로 구분하는 연속성 보정
- 최근값 smoothing과 note stability를 분리해 반응성과 안정성을 함께 확보
- 무거운 음정 계산을 Web Worker로 분리해 그래프/UI 끊김 감소
- 입력 dB, 소음 바닥, 판정 문턱, 검출 신뢰도를 화면에서 직접 확인 가능
- 최근 12초 그래프에서 한 가로줄 = 정확히 반음, 목표음 점선 표시, 그래프 고정 기능
- iOS에서 마이크/AudioContext가 꼬인 경우 오류 메시지와 재로드 복구 버튼 제공

## 설치 조건
PWA와 마이크는 HTTPS 환경이 필요합니다. 정적 호스팅(GitHub Pages, Cloudflare Pages, Netlify, Vercel 등)에 이 폴더 내용을 그대로 올린 뒤 Safari에서 주소를 열고 홈 화면에 추가합니다.

## 첫 측정
1. 처음에는 AirPods를 분리하고 조용한 곳에서 테스트합니다.
2. iPhone을 얼굴에서 약 30~50cm 떨어뜨립니다.
3. `마이크로 측정 시작`을 누르고 마이크 권한을 허용합니다.
4. 편한 크기로 `아—` 또는 `우—`를 2~3초 유지합니다.
5. 화면 아래 `입력 상태`에서 소리 감지와 검출 신뢰도를 함께 확인합니다.

## 테스트
`node tests/pitch-test.cjs`

합성 파형 기준 E2(82.41Hz), G2(98Hz), A2(110Hz), D3, A3, A4, E5를 검사합니다.
